Deploying GDP on AWS

A step-by-step runbook for provisioning GDP appliances on AWS using Terraform.

Prerequisites

  • An AWS account with permission to create EC2 instances, security groups, and key pairs
  • An AWS Access Key ID and Secret Access Key
  • GDP AMI images available in your AWS region
  • GDP license keys (base and append) for the Central Manager

Target audience

These instructions assume you are comfortable working at a Linux command line and have some familiarity with GDP, but do not require deep Terraform expertise.

Choose your path

IBM employees

You will provision a Linux VM on IBM Fyre to use as your Terraform host.

  • 1Set up Linux
    Create a Fyre VM, set up a user, configure GitHub SSH access, and clone the Terraform repository.
  • 2Install required software
    Install Terraform, expect, PowerShell, and the AWS CLI; create an AWS key pair; note your IP addresses.
  • 3Deploy and connect to the Central Manager
    Configure terraform.tfvars, run terraform apply to provision the Central Manager, then connect to it.
  • 4Deploy the Aggregators
    Configure terraform.tfvars and run terraform apply to provision the Aggregator instances.
  • 5Deploy the Collectors
    Configure terraform.tfvars and run terraform apply to provision the Collector instances.
Customers

You will use your own Linux machine as the Terraform host, with all required software already installed.

  • 1Deploy and connect to the Central Manager
    Configure terraform.tfvars, run terraform apply to provision the Central Manager, then open inbound rules on the security group and access the GDP web console and CLI.
  • 2Deploy the Aggregators
    Configure terraform.tfvars and run terraform apply to provision the Aggregator instances.
  • 3Deploy the Collectors
    Configure terraform.tfvars and run terraform apply to provision the Collector instances.

Repository

The Terraform scripts used in this runbook are available at github.com/IBM/terraform-aws-gdp.
